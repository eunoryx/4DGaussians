Complexity-Aware Density Management for 4D Gaussian Splatting

A 4D scene rendered just as well with 22% fewer Gaussians

Adaptive density control that adds Gaussians where a dynamic scene is complex and removes them where it is simple.

Rishita Mohan, Shiv Nadar University

The final model holds 22% fewer Gaussians, 28,177 → 22,045.

The fine stage of training went from 17m31s to 15m38s.

Test PSNR went from 40.34 to 40.57 dB, which is within noise.

One D‑NeRF scene, one run per method, RTX 4050 laptop.

Where the Gaussians end up

The centre of every Gaussian in each final model, drawn from the same angle with the same ink scale.

Notes and limits

What I did. I changed how 4D Gaussian Splatting decides where to add and remove Gaussians. Each one gets a complexity score from its accumulated position gradient. The top quarter is densified more readily and the bottom quarter is never densified. Gaussians that have faded out are pruned at every step, which the baseline does not do on a scene this small.

Limits. I tested this on one D‑NeRF scene, with one run per method, on an RTX 4050 laptop. The PSNR difference is within noise. I have not yet run an ablation that separates the pruning from the complexity-aware densification.

The code, the training plot and the method in detail are in the README.
